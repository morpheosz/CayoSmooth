# Cayo Smooth Expedition Archive

Institutional archive for the Cayo Smooth Expedition (1979–1980): a
fourteen-month charter voyage that departed with a crate of provisions
classified as cheese and returned with sixty-one recorded tracks and no
ketch. This repository holds the Archive's holdings and the site that
publishes them.

This is a documentation project, not a promotional one. Materials are
presented as recovered, not written. See `CLAUDE.md` for the tone rules
governing all content in this repository, and `CONTRIBUTING.md` before
submitting anything.

## Repo map

```

CONTRIBUTING.md         Style guide, PR process, canon-change process.
content/
  expedition/           The founding field report and voyage narrative.
  discography/          One entry per recovered track (61 total).
  artifacts/             Physical holdings: the blender, the journal, the
                          crate, the Rhodes.
  personnel/             Records on Expedition members, including Terry
                          (unresolved).
  notices/                The rights dispute and related correspondence.
  merch/                 Storefront copy.
site/                    Static site build (Eleventy).

```

## Site

Built with [Eleventy](https://www.11ty.dev/), reading Markdown with
frontmatter from `content/`, deployed to GitHub Pages. See `site/README.md`
for local build instructions.

## Status

Four tracks released at founding; a fifth, "Anchorage," has since been
cleared. Fifty-six remain unreleased, per Archive policy, on the advice
of a panel of cardiologists.
